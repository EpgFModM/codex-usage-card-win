# 安全与隐私

本文描述 Windows 社区预览版的实现边界，不代表独立安全审计或对未来 Codex 版本的保证。

## 数据访问

- 组件通过本地 Codex CLI app-server 的 `account/rateLimits/read` 和相关通知读取额度。CLI 依赖你已有的登录环境，并可能自行向服务端发起认证请求。
- 当前 Windows 组件不直接读取 `auth.json`，不调用旧版私有额度 HTTP 回退接口，不扫描项目、不请求聊天正文或读取聊天数据库。
- 组件不要求粘贴 API Key、会话 Cookie 或访问令牌。请保持 Codex 登录文件私密。
- 当前 Windows 组件未实现独立遥测上传；本说明不涵盖 Codex 客户端、CLI 或其他软件的网络行为。
- 状态与额度信息可能包含账号相关元数据。日志和诊断信息可能包含用户名、安装路径与启动详情。

## 本地调试接口

卡片通过 Chrome DevTools Protocol 加载到 Codex 界面，默认地址为 `127.0.0.1:39222`。Windows 启动器校验调试 WebSocket 的协议、回环地址和预期端口。

该接口能在应用页面执行 JavaScript，权限超出读取额度本身；绑定回环地址并不提供身份验证，也不隔离其他本机程序。**不要转发端口、对公网开放或允许不可信程序访问。**

`Stop.cmd` 停止组件并移除卡片，但不会关闭 Codex 已开启的调试接口。要关闭该接口，请完全退出 Codex，再使用原应用图标正常启动。

## 安装与运行的改动

- 发布包在解压目录运行，内含固定版本 Node.js；不要求管理员权限。
- `Install.cmd` 创建当前用户开始菜单快捷方式，并在 `%LOCALAPPDATA%\CodexUsageCard\shortcut.json` 记录归属。不会注册开机自启。
- 运行状态、错误与日志保存在 `%LOCALAPPDATA%\CodexUsageCard`。请勿未经脱敏直接公开这些文件。
- 组件通过专用入口启动带调试参数的 Codex，不修改客户端安装文件或签名；已有普通 Codex 会话时提示用户先退出，不强制终止会话。
- `Uninstall.cmd` 停止组件并移除归属记录匹配的快捷方式；解压目录和日志可由用户手动删除。
- 无自动更新。更新需手动获取发布包并核对校验值。

## 发布包与校验

仅从你认可的仓库或发布者获取文件。SHA256 用于检查文件是否与发布的校验值一致，不构成安全审计，也无法在发布账号本身被入侵时证明发布者身份。

构建时从 Node.js 官方站点下载固定运行时并验证固定哈希。源码、脚本和许可证随包分发；请在运行前按需审阅。

## 报告安全问题

不要在公开 Issue 中提交凭据、账号标识、聊天内容、未经脱敏的状态输出、完整日志或截图。

如仓库已启用 GitHub 私密漏洞报告，请从仓库 Security 页面使用该功能。若未启用，请只发布不含利用细节或隐私数据的概述，并请求私下报告渠道。普通兼容性问题可通过 [Issues](https://github.com/EpgFModM/codex-usage-card-win/issues) 提交，附客户端版本、Windows 版本及脱敏后的复现步骤。
